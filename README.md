# Салон красоты «Ольга Beauty» — Telegram-бот записи

Telegram-бот для записи клиентов в салон красоты на базе **aiogram 3 + Django (SQLite)**.

## Возможности

- Запись через бота тремя сценариями:
  - «Выбрать салон» → процедура → мастер → дата/время
  - «К любимому мастеру» → процедура → салон → дата/время
  - «Мне нужна процедура» → дата → время → мастер → салон
- Показ цен и длительности процедур
- Согласие на обработку персональных данных
- Запись клиентов, позвонивших по телефону, через скрытый раздел сотрудника (`/staff` по паролю) — слоты блокируются и не пересекаются с записями через бота
- Уведомление клиента в Telegram, если он уже известен боту
- Админка Django для управления салонами, услугами, мастерами, расписанием и записями

## Установка

Требуется Python 3.12+.

```bash
git clone <repo-url>
cd newversion

# виртуальное окружение
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # Linux/macOS

# зависимости
pip install -r requirements.txt
```

## Настройка

1. Создайте файл `.env` рядом с `bot.py` (шаблон — `.env.example`):

```ini
BOT_TOKEN=123456789:AA...
STAFF_PASSWORD=придумайте_пароль
```

   - `BOT_TOKEN` — токен бота из [@BotFather](https://t.me/BotFather)
   - `STAFF_PASSWORD` — пароль для входа в раздел сотрудника (команда `/staff`)

   Файл `.env` в `.gitignore`, в репозиторий не попадает.

2. Миграции и создание суперпользователя админки:

```bash
python manage.py migrate
python manage.py createsuperuser
```

3. Заполнение тестовыми данными (3 салона, 5 услуг, 3 мастера, клиенты, расписание):

```bash
python manage.py populate_db
```

## Запуск

```bash
python bot.py
```

Бот готов: `/start` — главное меню, `/staff` — раздел сотрудника (по паролю), `/cancel` — отмена текущего действия.

Админка: `http://127.0.0.1:8000/admin/` (запустить `python manage.py runserver`).

## Структура проекта

```
bot.py                  # точка входа бота
core/                   # настройки Django
bot_manager/            # модели: Salon, Service, Master, Client, TimeSlot, Appointment
salon_bot/              # хендлеры, клавиатуры, состояния, сервисы
```

## Безопасность

- Секреты хранятся только в `.env` (игнорируется git)
- Запись блокирует слот транзакционно (`select_for_update` + флаг `is_booked`) — двойная запись исключена и при конкурентном бронировании
- `/staff` защищён паролем
