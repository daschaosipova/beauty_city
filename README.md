Для запуска проекта на вашем локальном компьютере выполните следующие 5 шагов в терминале (командной строке) внутри папки вашего проекта.

### Шаг 1: Создание и активация виртуального окружения

Виртуальное окружение изолирует библиотеки этого проекта от остальной системы (необязательно).
1. Создайте окружение (папка `venv` появится в корне проекта):

```bash
python -m venv venv
```

2. Активируйте его:
- Для Windows (в PowerShell или Командной строке):

```bash
venv\Scripts\activate
```

- Для Mac / Linux (в Терминале):

```bash
source venv/bin/activate
```

>(После активации в начале строки терминала появится индикатор (`venv`)).

### Шаг 2: Установка зависимостей

Установите все необходимые библиотеки, которые мы использовали при проектировании:

```bash
pip install django aiogram environs requests
```

### Шаг 3: Настройка переменных окружения (Файл `.env`)

Проект настроен на безопасное чтение токенов, поэтому их нужно вынести в скрытый файл настроек.

1. В корневой папке проекта (там, где лежит файл `manage.py`) создайте файл с именем `.env` (обязательно с точкой в начале и без расширения .txt).

2. Откройте его в блокноте и добавьте одну строчку со своим токеном:

```text
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

> (Замените этот пример на реальный токен вашего бота, полученный у `@BotFather` в Telegram).

### Шаг 4: Настройка базы данных и Админки Django

Теперь создадим локальную базу данных SQLite и профиль главного управляющего сетью салонов.

1. Примените миграции (Django автоматически создаст таблицы Салонов, Мастеров, Услуг и Записей по нашим чертежам):

```bash
python manage.py migrate
```

2. Создайте суперпользователя для входа в панель управления:

```bash
python manage.py createsuperuser
```

> (Терминал по очереди попросит вас ввести Логин, Email и Пароль. При вводе пароля символы на экране отображаться не будут — это нормально, просто введите его и нажмите Enter).

### Шаг 5: Одновременный запуск системы

Чтобы проект работал полноценно, вам нужно запустить веб-сервер Django и Telegram-бота параллельно. Для этого откройте два окна терминала (в каждом из них должно быть активировано окружение `venv`).

1. В первом окне запустите сайт панели управления Django:

```bash
python manage.py runserver
```

Теперь вы можете открыть браузер по адресу `http://127.0.0.1:8000/admin`, войти под своим логином/паролем и наполнить базу данными: добавить первый салон, услугу и создать свободные слоты времени в расписании мастеров.

2. Во втором окне запустите самого Telegram-бота:

```bash
python main.py
```

В консоли появится сообщение: `🚀 Бот успешно запущен и готов к работе!`. Теперь можно заходить в Telegram и писать боту `/start` для тестирования автоматической записи.
